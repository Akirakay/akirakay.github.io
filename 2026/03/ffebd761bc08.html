LearnClaudeCode

Posted at 2026-03-15 Agent  Agent 

学习：https://tw93.fun/2026-03-12/claude.html

S01-Agent循环

“One loop & Bash is all you need” – 一个工具 + 一个循环 = 一个智能体。

S02-工具

“加一个工具, 只加一个 handler”_ – 循环不用动, 新工具注册进 dispatch map 就行。

加工具 = 加 handler + 加 schema。循环永远不变。

S03-ToDo Writer

“没有计划的 agent 走哪算哪” – 先列步骤再动手, 完成率翻倍。

主要解决：通过分步骤+计划表来解决多任务中， 模型会丢失进度的问题。

S04-SubAgent

“大任务拆小, 每个小任务干净的上下文” – 子智能体用独立 messages[], 不污染主对话。

避免任务进行过程中，上下文膨胀问题

S05-Skills

“用到什么知识, 临时加载什么知识” – 通过 tool_result 注入, 不塞 system prompt。

按需技能加载：扩展Claude code能力边界，也能解决浪费上下文token的问题

S06-上下文压缩

micro-compact + auto-compact + archival

“上下文总会满, 要有办法腾地方” – 三层压缩策略, 换来无限会话。

S07-任务系统

“大目标要拆成小任务, 排好序, 记在磁盘上” – 文件持久化的任务图, 为多 agent 协作打基础。

对比 TodoManager ，任务系统将计划落盘保存，不会丢失
对比 SubAgent ，任务系统则是将大的目标拆分独立的任务，多线程并行推进，互不干涉。每个任务是一个 JSON 文件, 有状态、前置依赖 (blockedBy) 和后置依赖 (blocks)

S08-后台任务

“慢操作丢后台, agent 继续想下一步” – 后台线程跑命令, 完成后注入通知。
